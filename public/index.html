Go Books API

REST API untuk kategori dan buku, berjalan di Netlify Functions dengan Netlify Database. Endpoint selain /health dan login memerlukan header Authorization: Bearer TOKEN_JWT.

MethodPath
GET/health
POST/api/users/login
GET, POST/api/categories
GET, PUT, DELETE/api/categories/:id
GET/api/categories/:id/books
GET, POST/api/books
GET, PUT, DELETE/api/books/:id
